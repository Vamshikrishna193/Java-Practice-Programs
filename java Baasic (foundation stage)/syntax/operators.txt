operators
---------
=>An operator is an special symbol that operates on data.
=>In java operators are divided into 9 categories.
1.Arthemitic operators
2.Relational operators
3.Logical operators
4.Increment and Decrement operators
5.Bitwise operators
6.Assignment operators
7.Conditional operators
8.Unary plus and unary minus operators
9.other operators

examples:                                    
=========
i. Arthemitic operator:                                                    
class Demo
{
 public static void main(String args[])
{
 int a=20;
 int b=5;

system.out.println(a+b);
system.out.println(a-b);
system.out.println(a*b);
system.out.println(a/b);
system.out.println(a%b);
}
}


ii.
class Demo
{
public static void main(String args[])
{
int a=10,b=5,c=2;
int d=a+c/b;
int e=a%b-c;
System.out.println(d);
System.out.println(e);
}
}


2.Relational operators:
i.class Demo
{
public static void main (String args[])
{
byte a=10,b=20;
System.out.println(a>b);
System.out.println(a<b);
System.out.println(a>=b);
System.out.println(a<=b);
System.out.println(a==b);
System.out.println(a!=b);
}
}


3.Logiacl operator:
i.
class Demo
{
public static void main (String args[])
{
int a=10,b=5,c=9;
boolean d=a>b && a>c;
boolean e=b>a || a>c;
System.out.println(d);
System.out.println(e);
}
}

ii.
class Demo
{
public static void main (String args[])
{
long a=33,b=21;
boolean c=a>5 && b<33;
System.out.println(c);
}
}
