Typecasting:
============
=>converting one type to another type is called Typecasting.
=>There are total 56 type conversions.
=>19 type conversions are called widening conversion.
=>23 type conversions are called Narrowing conversions.

examples:
--------
1.byte a=10;
int b=a;
System.out.println(b);

2.int a=10;
byte b=a;
System.out.println(b);

3.byte a=10;
byte b=20;
byte c=(byte)(a+b);
System.out.println();
